A program that writes exactly one funny line to `/output/entry.txt` for the
[One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae)
bounty on make.fun.

Run it with Node 22:

```sh
node main.ts
```

It writes a single joke — one line, no setup notes, no explanation — to
`/output/entry.txt`, deterministically (two runs produce byte-identical output).
